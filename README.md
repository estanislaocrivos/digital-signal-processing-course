# Digital Signal Processing Course 2026

Course record for the Digital Signal Processing course from Facultad de Ingeniería, Universidad Nacional de La Plata, La Plata, Buenos Aires, Argentina.

## Setup

### Requirements

- [Python 3](https://www.python.org/downloads/)

### Install

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pre-commit install
```
